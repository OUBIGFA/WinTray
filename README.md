## 简介

**WinTray** 是一款轻量实用的 Windows 开机整理工具，旨在解决开机后软件弹窗堆叠、脚本黑框闪烁的困扰，还你一个干净清爽的桌面。

核心场景：

* **窗口自动收起**：针对未提供“开机最小化到托盘”选项的软件，在启动后自动关闭主窗口，保持托盘后台运行。
* **脚本静默运行**：无窗口静默拉起 `.bat`、`.cmd`、`.ps1`、`.py` 等脚本，彻底告别命令行黑框窗口。

## 功能特性

* **托盘常驻**：系统通知区图标，支持一键打开设置和退出程序

* **受管程序列表**：可维护任意数量的程序，每个程序独立配置执行行为

* **开机自启动**：注册当前用户的登录计划任务，登录后立即启动，无需管理员权限

* **收进托盘**：启动方式选“收进托盘”后，开机时自动收起目标窗口，程序继续在托盘运行

* **开机即启动**：只替换程序的开机触发方式，保留原自启参数、静默行为和管理员权限；已有登录任务直接复用，避免重复启动

* **最长等待程序窗口**：0–120 秒可调，应对启动慢、窗口迟迟不出现的程序

* **收起前等待**：每个程序可单独设置运行满多少秒后再收起窗口，跳过登录等前置弹窗（如新版 QQ）

* **错峰启动**：按程序列表顺序依次拉起（拖动程序即可调整顺序），默认间隔 3 秒；可在设置页的“程序之间的启动间隔”调整为 0–120 秒，缓解开机集中启动造成的资源争抢

* **重置并清理数据**：可在设置页一键清理本地配置/日志并恢复默认状态

* **双语界面**：内置简体中文 / English，可即时切换

* **单实例保护**：防止重复启动，避免配置冲突

## 下载与使用

WinTray 仅提供**便携版**，无需安装。

前往 [Releases](../../releases) 页面，下载最新版本的 `WinTray-Portable.zip`，解压后直接运行 `WinTray.exe` 即可。

* 配置、日志与原自启状态的恢复备份写入 `%LOCALAPPDATA%\WinTray\`

* 删除前请先在设置页使用“重置…”恢复被迁移的原自启并清理 WinTray 的任务，再删除程序文件夹；不要直接删除尚有恢复备份的数据目录

## 支持托管的程序类型

WinTray 支持添加以下类型的程序到受管列表，在开机时自动启动并处理窗口：

| 类型            | 文件扩展名           | 启动行为                          |
| ------------- | --------------- | ----------------------------- |
| 可执行程序         | `.exe`          | 默认正常启动，可选择“收进托盘”把界面收进托盘；控制台程序由 WinTray 代为提供托盘图标 |
| 批处理脚本         | `.bat` / `.cmd` | 默认后台启动（不显示命令行窗口）              |
| PowerShell 脚本 | `.ps1`          | 默认后台启动                        |
| Python 脚本     | `.py` / `.pyw`  | 默认后台启动，分别调用 `python.exe` / `pythonw.exe` |

> 非 `.exe` 类型的脚本（`.bat` / `.cmd` / `.ps1` / `.py` / `.pyw`）添加时默认使用“后台启动”，不能选“收进托盘”和“开机即启动”。

> **注意**：有些软件包含多个 `.exe`（启动器、更新器等），请选择显示主界面的那个；选错会导致“收进托盘”不生效。

### 每个程序的独立配置项

* **启动方式**（四选一）：**收进托盘** —— 启动后收起主窗口，程序继续在托盘运行 / **后台启动** —— 不显示任何窗口，适合脚本和命令行工具 / **开机即启动** —— 只替换原开机触发方式 / **正常启动** —— 只启动，窗口保持原样

* **收起前等待**：配合“收进托盘”，0–600 秒；有登录窗口的程序（新版 QQ 建议 10–15 秒）用它可以跳过登录过程

* **启动参数**：可选，正常/后台/收进托盘模式下传给程序

* **开机后自动启动此程序**：取消后停止 WinTray 的启动安排，程序自身的自启保留或恢复

> 无托盘图标的控制台程序（`syncthing.exe`、`frpc.exe` 等）选“收进托盘”后，由 WinTray 代为提供托盘图标：左键显示/隐藏窗口，右键可显示、隐藏、结束托管或退出程序。

### 收进托盘的启动过程

启动时尽量隐藏界面，等程序运行满“收起前等待”设定的秒数后收起窗口，保留原生托盘。收起失败或操作取消时，窗口恢复可见。

**部分程序仍可能短暂闪现界面。** 需要手动登录的程序请先完成登录，或选“正常启动”。“托盘收纳”需单独勾选。

### 开机即启动：保留原启动设置

只替换开机触发方式，程序自身的启动配置一律不动。

* **沿用原入口**：已有的登录任务、注册表自启和启动文件夹快捷方式全部复用，只切换可恢复的启用状态以避免双启动；旧版遗留的重复任务会被清理。
* **参数与权限照旧**：保留原自启参数、静默行为、权限和工作目录；新建管理员任务首次需确认。
* **启动时机**：新建任务在 WinTray 和桌面就绪后立即启动，不参与错峰间隔；已有任务保留原延迟，自定义时间照常生效。等待超时会报错。
* **撤销干净**：切换模式、暂停、移除程序或关闭 WinTray 自启时，替代任务被删除，启用状态还原，程序自身的自启不受影响。
* **无法识别时报错**：原入口缺失、被禁用或命令有歧义时直接报错，不猜测、不降级；这类程序请改用“正常启动”。

### 托盘收纳

在程序列表勾选“托盘收纳”，把该程序已有的托盘图标收进 WinTray 的右键菜单。需 Windows 11，仅支持 `.exe`。

* 原图标从任务栏和 `^` 弹出区移除；菜单沿用程序当前图标与名称
* 左键等同单击原图标，右键打开程序自身的托盘菜单
* 取消勾选或正常退出 WinTray 时恢复原图标；未勾选的程序保留原生托盘
* 收纳失败时尝试恢复原图标，并在日志中记录原因

### 自定义时间

勾选后可设置：

* **延后启动**：开机后 **0–1440 分钟**启动，默认 **0**。
* **自动退出**：运行满 **0–1440 分钟**后退出（含子进程），默认 **30**，**0** 为不退出；取消“开机启动此程序”后仍生效。
* **限制自动运行次数**：最近 **1–365 天**内最多自动运行 **1–1000 次**，默认不启用，启用时默认 **1 天 1 次**；**1 天 = 24 小时**，重启或跨午夜不清零。

次数限制仅约束开机自动运行，手动打开和“立即启动”不受限。启用后接管程序原有开机自启，关闭限制后恢复原有启动安排；接管失败时会提示错误。需要管理员权限的计划任务会请求一次确认。

取消“自定义时间”后，上述设置均不生效。

### 错峰启动

设置页的“程序之间的启动间隔”控制两次启动的最小间隔，默认 **3 秒**，可设 **0–120 秒**；按列表顺序依次启动（拖动调整顺序），“立即启动”不受影响。

### 典型场景举例

| 场景                          | 配置方式                        |
| --------------------------- | --------------------------- |
| 微信 / 钉钉等开机自启并自动折叠到托盘   | 添加 `.exe`，启动方式选“收进托盘”       |
| 新版 QQ 开机自启、登录后折叠到托盘 | 添加 `QQ.exe`，选“收进托盘”，“收起前等待”设为 10–15 秒 |
| syncthing / frpc 等控制台程序开机后台运行并可随时从托盘打开 | 添加 `.exe`，启动方式选“收进托盘”，WinTray 代为提供托盘图标 |
| 内网穿透脚本（frpc / ssh 隧道）开机后台运行 | 添加 `.bat` / `.ps1`，启动方式选“后台启动” |
| Python 爬虫/服务后台静默运行          | 添加 `.py`，启动方式选“后台启动”         |
| 仅开机自启，不处理窗口                 | 添加程序，启动方式保持“正常启动”           |
| 以管理员身份运行的工具开机快速自启             | 添加 `.exe`，启动方式选“开机即启动”        |

## 启动参数

| 参数                  | 说明                                       |
| ------------------- | ---------------------------------------- |
| `--background`      | 后台启动，不显示主窗口（开机自启使用）                      |
| `--autorun`         | 执行开机启动项任务（开机自启使用）                          |
| `--cleanup-restore` | 恢复原自启并清理 WinTray 任务与数据；建议通过设置页使用 |
| `--host`            | 兼容旧版调用，新版无需使用                            |

**开机任务完成后自动退出**（设置页可选）：开机任务结束后自动退出；有程序启用托盘收纳时不会自动退出；仍有托盘图标在工作时会等待，最后一个结束后退出。

**后台静默运行**（设置页底部及托盘菜单）：隐藏设置窗口，后台运行；再次运行 WinTray 可恢复窗口。

不勾选“开机任务完成后自动退出”时，WinTray 常驻自身托盘图标；“开机时不弹出 WinTray 窗口”决定这种模式下是否显示主窗口。

## 常见问题

**Q：程序运行后没有主窗口怎么进入设置？**
A：右键托盘中的 WinTray 图标选择“打开 WinTray”，或重新运行 `WinTray.exe`。

**Q：开机自启生效后如何取消？**
A：在设置页关闭“开机时自动运行 WinTray”。WinTray 自身的任务和自启项会删除，程序的迁移任务会撤销；程序原有的自启会保留或恢复，而不是被一起禁用。

**Q：新版 QQ 开机后没有折叠到托盘，反而登录失败或直接退出了？**
A：QQ 启动时先显示登录窗口，过早收起会使其直接退出。请把“收起前等待”设得长于整个登录过程（自动登录通常 15–30 秒）。

**Q：QQ 自带开机自启和 WinTray 同时启用，会不会双开？**
A：不会。WinTray 发现该程序已由系统 `Run` 自启接管时，只等待系统拉起它，**不会补启动**，因此不会双开。

**Q：加入列表的程序没有被自动收进托盘？**
A：确认启动方式选的是“收进托盘”、已开启“开机时自动运行 WinTray”；程序启动较慢时，调大“最长等待程序窗口”。
