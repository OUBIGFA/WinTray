## 简介

**WinTray** 是一款轻量实用的 Windows 开机整理工具，旨在解决开机后软件弹窗堆叠、脚本黑框闪烁的困扰，还你一个干净清爽的桌面。

核心场景：

* **窗口自动收起**：针对未提供“开机最小化到托盘”选项的软件，在启动后自动关闭主窗口，保持托盘后台运行。
* **脚本静默运行**：无窗口静默拉起 `.bat`、`.cmd`、`.ps1`、`.py` 等脚本，彻底告别命令行黑框窗口。

## 功能特性

* **托盘常驻**：系统通知区图标，支持一键打开设置和退出程序

* **受管程序列表**：可维护任意数量的程序，每个程序独立配置执行行为

* **开机自启动**：注册当前用户的登录计划任务，登录后立即启动，早于资源管理器逐个拉起的 `Run` 自启项，无需管理员权限；计划任务不可用时退回写入 `Run` 注册表项

* **错峰启动**：按程序列表顺序依次拉起，默认间隔 3 秒；可在全局设置中调整为 0–120 秒，缓解开机集中启动造成的资源争抢

* **收进托盘**：程序列表中配置后，开机任务触发时自动收起目标窗口，程序继续在托盘运行

* **最长等待程序窗口**：0–120 秒可调，应对启动慢、窗口迟迟不出现的程序

* **收起前等待**：每个程序可单独设置运行满多少秒后再收起窗口，跳过登录等前置弹窗（如新版 QQ）；对程序自带开机自启拉起的实例同样生效

* **重置并清理数据**：可在主窗口一键清理本地配置/日志并恢复默认状态

* **单实例保护**：防止重复启动，避免配置冲突

## 下载与使用

WinTray 仅提供**便携版**，无需安装。

前往 [Releases](../../releases) 页面，下载最新版本的 `WinTray-Portable.zip`，解压后直接运行 `WinTray.exe` 即可。

* 配置与日志写入 `%LOCALAPPDATA%\WinTray\`，不依赖任何注册表安装项

* 删除前请先退出 WinTray：运行期间 `WinTray.exe` 仍被占用，无法删除；关闭程序后删除文件夹即可彻底移除

## 支持托管的程序类型

WinTray 支持添加以下类型的程序到受管列表，在开机时自动启动并处理窗口：

| 类型            | 文件扩展名           | 启动行为                          |
| ------------- | --------------- | ----------------------------- |
| 可执行程序         | `.exe`          | 默认正常启动，可选择“收进托盘”把界面收进托盘；控制台程序由 WinTray 代为提供托盘图标 |
| 批处理脚本         | `.bat` / `.cmd` | 默认后台启动（不显示命令行窗口）              |
| PowerShell 脚本 | `.ps1`          | 默认后台启动                        |
| Python 脚本     | `.py` / `.pyw`  | 默认后台启动，分别调用 `python.exe` / `pythonw.exe` |

> 非 `.exe` 类型的脚本（`.bat` / `.cmd` / `.ps1` / `.py` / `.pyw`）添加时默认使用“后台启动”，不能选“收进托盘”。

> **重要提醒**：有些软件包包含多个 `.exe` 文件，例如启动器、更新器、辅助进程和真正的主程序。添加程序时，请选择实际负责显示主界面的主程序。选错 `.exe` 可能导致程序虽然启动，但 WinTray 找不到对应窗口，“收进托盘”不会生效。

### 每个程序的独立配置项

* **启动方式**：**正常启动**（只负责启动，窗口保持原样）/ **收进托盘**（启动后收起主窗口，程序继续在托盘运行）/ **后台启动**（不显示任何窗口，适合脚本和命令行工具）

* **收起前等待**：选择“收进托盘”后可用，0–600 秒。程序进程运行满设定的秒数后，WinTray 才查找并收起窗口，用于跳过启动时的登录窗口——新版 QQ 建议设为 10–15 秒。延迟从进程创建时开始计算，程序自带开机自启拉起的实例同样适用，不必关闭它自带的自启

* **启动参数**：传给程序的命令行参数

* **开机后自动启动此程序**：取消勾选即暂停该程序，开机时跳过；“立即启动”仍可用

> 对没有自带托盘图标的控制台程序（`syncthing.exe`、`frpc.exe` 等），关闭窗口会直接结束进程，因此“收进托盘”改为隐藏其控制台窗口，并由 WinTray 代为提供托盘图标：左键显示/隐藏窗口，右键菜单可显示、隐藏、结束托管或退出程序。图标统一由 WinTray 主进程持有，不会多开进程。

### 错峰启动

全局设置中的“程序之间的启动间隔”决定 WinTray 两次拉起程序之间至少等待多少秒，默认 **3 秒**，可设 **0–120 秒**（0 表示不等待），重型程序较多时可调大。启动按列表顺序进行，首个程序不额外等待，最后一个启动后也不会再多等一轮；暂停、已在运行或启动失败的项不占间隔。“立即启动”不受影响。

该间隔只作用于 WinTray 实际拉起的程序：已启用的系统 `Run` 自启项仍由 Windows 安排，WinTray 只等待并处理它们的窗口，不会改动其他程序的自启设置。

### 典型场景举例

| 场景                          | 配置方式                        |
| --------------------------- | --------------------------- |
| 微信 / 钉钉等开机自启并自动折叠到托盘   | 添加 `.exe`，启动方式选“收进托盘”       |
| 新版 QQ（NT 架构）开机自启、登录完成后折叠到托盘 | 添加 `QQ.exe`，启动方式选“收进托盘”，并把“收起前等待”设为 10–15 秒以跳过登录窗口；QQ 自带的开机自启可以保留 |
| syncthing / frpc 等控制台程序开机后台运行并可随时从托盘打开 | 添加 `.exe`，启动方式选“收进托盘”，WinTray 代为提供托盘图标 |
| 内网穿透脚本（frpc / ssh 隧道）开机后台运行 | 添加 `.bat` / `.ps1`，启动方式选“后台启动” |
| Python 爬虫/服务后台静默运行          | 添加 `.py`，启动方式选“后台启动”         |
| 仅开机自启，不处理窗口                 | 添加程序，启动方式保持“正常启动”           |

## 启动参数

| 参数                  | 说明                                       |
| ------------------- | ---------------------------------------- |
| `--background`      | 后台启动，不显示主窗口（开机自启使用）                      |
| `--autorun`         | 执行开机启动项任务（开机自启使用）                          |
| `--cleanup-restore` | 清空 `%LOCALAPPDATA%\WinTray\` 数据目录后退出        |
| `--host`            | 兼容旧版调用，新版无需使用                            |

**开机任务完成后自动退出**（设置页可选）：没有托管图标时任务结束即退出；仍有托管图标时隐藏设置窗口和 WinTray 自身图标、只保留程序图标，最后一个托管结束后退出。再次运行 WinTray 会打开已有实例的设置，正在操作设置或手动启动时不会自动退出；手动选择“退出 WinTray”则会取消未完成的任务、恢复被隐藏的窗口再退出。

**后台静默运行**（设置页底部“退出 WinTray”旁，以及托盘右键菜单，随时可用）：隐藏设置窗口和 WinTray 自身图标，被隐藏的程序窗口保持隐藏，syncthing、frpc 等控制台程序的托管图标继续可用；进行中的任务会继续完成，最后一个托管结束后自动退出，没有托管时立即退出；再次运行 WinTray 恢复显示。

不勾选“开机任务完成后自动退出”时，WinTray 常驻自身托盘图标；“开机时不弹出 WinTray 窗口”决定这种模式下是否显示主窗口。

## 常见问题

**Q：程序运行后没有主窗口怎么进入设置？**
A：右键系统托盘中的 WinTray 图标，选择“打开设置”；如果自动退出模式下只剩受管程序的图标，重新运行 `WinTray.exe` 即可打开设置，不会创建第二个主进程。

**Q：开机自启生效后如何取消？**
A：在设置页取消勾选“开机时自动运行 WinTray”，程序自动删除对应的登录计划任务和注册表项。也可以在“更多功能 → 故障排查”中点击“删除登录计划任务”，确认后会删除计划任务和自启项并关闭开机自启动。

**Q：新版 QQ 开机后没有折叠到托盘，反而登录失败或直接退出了？**
A：新版 QQ 启动时先显示登录窗口，此时收到关闭消息会直接退出。为该程序设置“收起前等待”，让延迟覆盖整个登录过程（自动登录通常 15–30 秒，手动登录请预留更长时间）。无论 QQ 由 WinTray 启动还是由它自带的开机自启拉起，WinTray 都会等它运行满延迟时间、主面板出现后再收起。

**Q：QQ 自带开机自启和 WinTray 同时启用，会不会双开？**
A：WinTray 会检查直接指向所配可执行文件的 `HKCU/HKLM Run` 自启项（含 32 位项），并尊重任务管理器中的禁用状态。发现启用项后，只等待系统启动该程序，最多等待 300 秒；发现进程后再按“收起前等待”处理窗口。超时会记录明确日志，**不会补启动**，避免系统稍后启动造成双开。“立即启动”仍可手动启动未运行的程序。本检测不涵盖任务计划、启动文件夹或第三方启动器的间接自启，也不会修改其他程序的自启设置。

**Q：加入列表的程序没有被自动收进托盘？**
A：确认该程序的启动方式选的是“收进托盘”，且 WinTray 是以 `--autorun` 参数触发的（开机自启时由系统自动传入）。程序启动较慢时，可调大“最长等待程序窗口”。
